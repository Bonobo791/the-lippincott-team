# Plan 1: Brand Restyle + Site Chrome — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the Astro + Tina starter to the Lippincott Team brand (colors, fonts, header, footer) and remove the starter's space theme, while keeping `pnpm build:local` green throughout.

**Architecture:** This is plan 1 of 4 for the WordPress → Astro migration (spec: `docs/superpowers/specs/2026-07-24-wordpress-to-astro-tina-migration-design.md`). It touches only the design system (`src/styles/global.css`), site chrome (`src/components/Header.astro`, `src/components/Footer.astro`), the global-config Tina schema (nav dropdowns, footer blurb), and the global config content (`src/content/config/config.json`). No page/block/content migration happens here.

**Tech Stack:** Astro 7, TinaCMS 3, Tailwind CSS v4 (`@tailwindcss/vite`), Fontsource fonts, pnpm.

## Global Constraints

- Package manager is **pnpm**, never npm/yarn. Node >= 22.22.0.
- Tina field names: **letters, numbers, and underscores only (no hyphens)**.
- Verification command is `pnpm build:local` (fully offline; `pnpm build` fails without TinaCloud creds). It must pass after every task. **Note:** `pnpm build:local` is a per-task *gate* only — for visual/frontend iteration use `npx astro dev --port 4322` (not `pnpm dev`; separate port, leaving 4321 for `pnpm preview` gates/final shots) and screenshot against the dev server (sub-second HMR, no build per round); see the `visual-loop` skill.
- `tina/__generated__/` is regenerated by the build — never hand-edit it, but do commit its changes after schema edits.
- Brand tokens (from spec): primary red `#c22737`, headings `#101828`, grays `#475467` / `#667085`, light bg `#f9fafb`. Fonts: Montserrat 600 (headings), Libre Baskerville 700 (display serif), Arimo (body/UI).
- IDX/search/buyers/sellers links are **external** to Sierra: `https://www.thelippincottteam.com/...`.
- Do not delete content files (`src/content/page/*.mdx`, `src/content/blog/*.mdx`) or `public/blog-placeholder-*.jpg` — demo content gets replaced in plans 3–4 and must keep building until then.
- The site ships zero React; all interactivity is vanilla JS (`<script is:inline>`), matching the existing `Header.astro` mobile-menu pattern.
